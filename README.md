# AWS Internship – Week 1

AWS Cloud Basics internship (Skill Nexis), Week 1: account setup, IAM, EC2, and core AWS services.

## What I did
- Set up IAM users with different permission levels (read-only and scoped S3 access)
- Explored AWS Regions and Availability Zones (Asia Pacific - Mumbai)
- Launched and terminated an EC2 t3.micro instance
- Explored EC2, S3, RDS, and Lambda consoles
- Completed the IAM & S3 mini project: created a bucket, tested a public bucket policy, then locked it back down

## Files
- `Week 1 – AWS Basics.pdf` – answers to the 5 core practice questions
- `Week1-Assignment.pdf` – full walkthrough with screenshots

## Key learning
Practiced the principle of least privilege by giving IAM users only the permissions they need, 
rather than full admin access, and understood how S3's Block Public Access setting works 
together with bucket policies to control public access.
